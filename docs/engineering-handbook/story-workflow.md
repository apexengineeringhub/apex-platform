# Story Workflow

Every Project APEX story follows this workflow.

---

## Phase 1 - Planning

- [ ] Jira Story Created
- [ ] User Story Defined
- [ ] Acceptance Criteria Reviewed
- [ ] Definition of Done Reviewed
- [ ] Feature Branch Created

---

## Phase 2 - Development

- [ ] Code Implemented
- [ ] Build Successful
- [ ] Manual Testing Completed
- [ ] Code Reviewed

---

## Phase 3 - Completion

- [ ] Git Commit Created
- [ ] Code Pushed
- [ ] Project Status Updated
- [ ] Engineering Logbook Updated
- [ ] Jira Status Changed to Done
