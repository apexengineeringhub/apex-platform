# Project APEX
> Building Enterprise AI Backend Systems with Java, Spring Boot and AI.
  This repository contains Project APEX, a hands-on engineering journey to build production-ready AI backend applications using Java, Spring Boot, RAG, AI Agents and Cloud Native technologies.

## Vision 

To become an Enterprise AI Backend Engineer by building production-ready AI applications using Java, Spring Boot, RAG, AI Agents and Cloud Native technologies.

## Objectives

- Become an Enterprise AI Backend Engineer
- Build production-ready AI applications
- Master Java & Spring Boot
- Learn Spring AI & LangChain4j
- Learn RAG and AI Agents
- Learn Docker & Kubernetes
- Follow enterprise engineering practices


## Tech Stack 
- Java 21
- Spring Boot
- Spring AI
- LangChain4j
- PostgreSQL
- pgvector
- Docker
- Kubernetes
- Redis
- Kafka
